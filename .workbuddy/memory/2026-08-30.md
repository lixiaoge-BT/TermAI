## 光标闪烁拖影复发修复（20:23→20:38 修正）
- **用户第三次报"输入命令后光标闪、后面字也忽现忽看不到"**。此前已切 Canvas 渲染器，但正式包 `release/0.1.0` 的 asar 经核验确实含 `CanvasAddon`/`CanvasRenderer`，说明根本不是"没打包"。
- **首轮错误修复（20:23）**：删掉整段自定义 `.xterm-cursor` CSS 闪烁动画 + `!important`，并加灰度抗锯齿。结果用户反馈"光标现在不闪了"——根因是：本应用 Electron 环境里 xterm **原生 blink 依赖焦点、实际未触发**（这正是当初那段 CSS 动画被加进来的原因），去掉它后失去唯一闪烁来源。
- **正确修复（20:38）**：
  1. 保留 CSS 强制闪烁（`@keyframes termai-cursor-blink` + `.xterm .xterm-cursor { animation: ... }`），保证光标始终闪；
  2. 给 `.xterm-cursor` 加 `will-change: opacity`，把它单独提升为合成层——opacity 动画只重绘光标自身，绝不牵连邻字（这是根治邻字拖影的关键，比单纯灰度 AA 更稳）；
  3. 终端整体保留 `-webkit-font-smoothing: antialiased` + `-moz-osx-font-smoothing: grayscale` 灰度抗锯齿兜底。
- **关键验证**：`node_modules/xterm/css/xterm.css` 中光标 blink 是 JS 驱动、非 CSS animation，故原生 blink 在焦点缺失时不工作；CSS 强制动画是必要兜底。`will-change:opacity` 确保 opacity 动画不触发整行重绘。
- check/lint/81 测试全绿、打包到 `release/build-tmp`，asar 核验 `termai-cursor-blink`=2、`.xterm-cursor{animation:termai-cursor-blink...;will-change:opacity}` 命中、灰度兜底命中。
- **可复用经验**：xterm 终端"光标闪 + 邻字忽明忽暗"= 给 `.xterm-cursor` 强加 opacity 动画时整行被重绘 + subpixel AA 位移。正确做法：保留 CSS 闪烁动画（原生 blink 在本环境不触发），但给 `.xterm-cursor` 加 `will-change:opacity` 把它隔离到独立合成层，并全局灰度抗锯齿。绝不能用 `animation:none !important` 删掉闪烁动画（会让光标不闪）。

## 光标不闪终局修复（21:05）
- **用户第四次报"光标还是不能正常闪烁"**。根因定位错误：**当前包其实用的是 Canvas 渲染器**——Canvas 把光标画在 `<canvas>` 上，`.xterm-cursor` 不是 DOM 节点，所以 `.xterm .xterm-cursor { animation: ... }` 这个 CSS 选择器**根本没有目标元素**，动画空转 → 光标不闪。之前几轮在 CSS 上打补丁全部无效，正因如此。
- **终局正确修复（回归 DOM 渲染器方案）**：
  1. `XTerminal.tsx` 移除 `@xterm/addon-canvas` 导入与 `term.loadAddon(new CanvasAddon())`；
  2. `cursorBlink` 在构造选项与 `assertBlinking()` 里**改为 false**（关掉 xterm 原生 blink，原生 blink 才会在聚焦切换时整行重绘导致邻字闪烁）；
  3. 由 `src/index.css` 的 `termai-cursor-blink` 动画驱动 `.xterm-cursor`（DOM 节点）稳定闪烁，不依赖焦点；`.xterm-cursor` 保留 `will-change:opacity` 合成层隔离、终端保留灰度抗锯齿兜底。
- **核心结论（务必记住）**：xterm 的 Canvas 渲染器 与 "用 CSS 动画控制 `.xterm-cursor` 闪烁" 是**互斥**的——canvas 光标无对应 DOM 节点，CSS 动画无效。要 CSS 驱动闪烁就必须用 DOM 渲染器；要消除邻字闪烁就不能用原生 blink，必须靠 `will-change:opacity` + 灰度 AA。
- check/lint/81 测试全绿、打包 `release/build-tmp`，asar 核验 `Canvas 渲染器加载失败`=0、`termai-cursor-blink`=2、`.xterm-cursor{animation:termai-cursor-blink...;will-change:opacity}` 命中。
