**改动**
- `services/agent.ts` 新增 `digestFailure()`：**取命中行里的尾部 2 条**（不是前 2 条 —— yum 会先打 `No package x available.`，根因在最后）。`FAIL_BARE_HEADER_RE` 剔除 `Error Summary` 这类只有标题的行；无命中退回尾部 2 行。
- `buildPriorRunBrief`：失败项用 `digestFailure`；新增 `blockedCommands` 段落；措辞改成「背景资料 + 怎么用（续做/换事两条路）+ 判断依据是用户原话」。
- `AgentBucket.blockedCommands?: string[]` 跨 run 保留（reset 时随 bucket 删除），`droppedProtected` 时 `patchBucket` 落库。
- 新增 `judgeGoalRelation()`：命中**强承接语**（继续/接着/再试/上面/那个/它/卸了再…）才判 continue，否则 fresh。`isFresh = !messages.length || (goalChanged && !continuing)` → 续接时继承完整 messages，`buildResumeNote` 死分支复活。
- 判定原则：**误判成新任务的代价是「多说一句」，误判成续接的代价是「答非所问」**，所以宁可 fresh。
