## 移除 Alt 触发的原生菜单栏

- 现象：Windows 上按 Alt 弹出 File/Edit/View/Window/Help（截图红线标注）。
- 仅 `Menu.setApplicationMenu(null)`（app 级）不够：实测平时无菜单，按 Alt 仍弹出默认菜单。
- 真正生效：`createWindow()` 里对 BrowserWindow 实例调 `newWin.setMenu(null)`（窗口级），两处都保留作双保险。
- Electron 文档：`setApplicationMenu(null)` 的「removing the menu bar」在 Windows 上未按预期覆盖 Alt 系统菜单；窗口级 `setMenu(null)` 才是彻底方案。
- 实跑验证：python+ctypes 模拟 Alt（keybd_event VK_MENU）+ GDI BitBlt 截窗口 BMP（PIL 不可用，手写 BMP 文件头），对照截图确认按 Alt 后顶部直接是应用内容、无菜单栏。
- 验证：npm test 628/628 通过，npm run build 全绿。
