### 实锤高危（4 条，均已亲自跑探针确认）

1. **P0 安全网关被反引号/$() 绕过 → 静默执行**（`src/services/safety.ts:222`）
   规则 `(?:\/|\/\*)(?:\s|$)` 要求 `/` 后紧跟空白/行尾；`splitTopLevel` 只跟踪引号**不跟踪 `$(`/反引号**，
   故 `echo \`rm -rf /\`` 整段落进 `bin=echo` → 命中只读白名单 → `risk=none`。
   生产默认（`autoRunMedium=false`）实跑结果：`rm -rf /` 弹窗 vs `echo $(rm -rf /)` **静默执行**。
   同批静默：`eval "rm -rf /"`（low）、`xargs rm -rf < /dev/null`（low）。
   确认判定在 **`src/store/agent.ts:1197`**（不是 services/agent.ts）。

2. **P0 提示词注入：远端输出可注入 Agent 协议标记**（`src/services/agent.ts:1716` buildObservation）
   远端 motd/日志里的 `<<<RUN>>>...<<<END>>>` 原样进 messages，仅三反引号包裹，**无转义/无来源标记**。
   完整链：buildObservation 保留标记 → 模型复述 → `parseAgentReply` 解析成真指令。
   `sanitizeOutput`/`digestOutput` 同样保留（digest 还会 `|` 拼接成一行）。

3. **P0 SSH 主机密钥完全不校验**（`electron/main/ssh.ts:134-197`）
   `buildConnectConfig` 9 个字段无 `hostVerifier`/`hostHash`；ssh2 缺 `hostVerifier` 时默认接受。
   附带启用 `ssh-dss`/`group1-sha1`/`3des-cbc`/`hmac-md5`（为兼容 CentOS6/7 老放宽）。

4. **P0 Agent 三层去重防线被单点打穿**（`store/agent.ts:1320` 传 `isOk(res)` + `agent.ts:747/754/794` 三处要 `lastOk`）
   全失败的一行命令里 `lastOk` 恒 false ⇒ 逐字闸门/同族闸门/failTreadmill **同时失效**，
   只剩 `MAX_AGENT_STEPS=20`。**8 段上限实测有效**（记忆里记的「失效」有误）。
