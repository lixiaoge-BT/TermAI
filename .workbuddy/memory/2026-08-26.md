# 2026-08-26 TermAI 修复记录

## 1. 便携版启动不了（根因 + 修复）
- 根因：上一轮 `npm run dist` 构建便携版时被多次 `taskkill /IM app-builder.exe /F` 打断，产出的 `TermAI 0.1.0.exe` 是**截断的（64.8MB，正常应约 74MB）**，缺 Electron 主体 → 无法启动。
- 修复：干净重建，便携版现为 74.4MB（MZ 头有效，`--version` 退出码 0）。
- 附加健壮性：main 进程加 `uncaughtException`/`unhandledRejection` → `dialog.showErrorBox`，窗口 `show:false` 加载完再 `show()` + 5s 兜底，背景色改深色避免白闪。

## 2. 安装版速度 + “下一步消失”
- asar 从 62MB 瘦身到 23.6MB：剔除 `node-pty/deps`（winpty 源码，仅编译期需要，运行时用 prebuilds/win32-x64 预编译 .node）与所有 `*.map`。
- `files` 加 `!**/*.map`、`!node_modules/node-pty/deps/**`；保持 ssh2/asn1/bcrypt-pbkdf/cpu-features/nan/buildcheck/node-pty 完整。
- 安装向导“点下一步内容消失、需重跑才能装”高度疑似 **Windows SmartScreen/杀软拦截未签名安装包**（环境性问题，重跑即绕过）。无法纯靠代码根治，建议：右键“以管理员身份运行”、属性解除锁定，或后续代码签名。也可直接用便携版（无需安装）。
- 注：electron-builder 24 的 NSIS 不支持 `nsis.compression`，正确选项是 `useZip`（已弃用，因会让安装包膨胀到 117MB；asar 瘦身已足够提速）。

## 3. AI 助手命令无法执行到本地终端（根因 + 修复）
- 根因：`XTerminal.tsx` 的 `__termai_writeTerminal` 是**每个终端实例各注册一个全局函数**，多标签时后者覆盖前者；且本地终端 `status==="connected"` 时错误地走 `window.ssh.write`（本地无 SSH），否则只 `term.write` 回显不执行 → 命令进不了 shell。
- 修复：改为**全局单例**，按 store 中 session 判断 `!st.hostId` → 本地走 `window.localTerminal.write`，SSH 走 `window.ssh.write`；并新增 `termRefsBySession` 注册表，让连接/执行回显写入正确的终端（解决多标签串台）。`__termai_connect` 同样改为单例。

## 构建备注
- 沙箱 `rm -rf` 大目录会被 genie-safe-delete 拦截（>50 目标需确认），勿用；让 electron-builder 原地覆盖即可。
- `npm run dist` 正常产出 nsis + portable。

## 4. 文件传输本地只能看到 C 盘、无法切盘
- 根因：后端 `localFs.listRoots()` 已能枚举 A-Z 所有可用盘符，但前端 `FileManager.tsx` 初始化后只取 `roots[0]`，且面包屑里没有盘符选择器。
- 修复：保留 `localRoots` 状态并传给本地 `Pane`；在面包屑处加一个盘符下拉框（`select`），列出所有可用盘符并切换；多盘符时隐藏面包屑中的根目录项，避免重复。
- 涉及文件：`src/components/FileManager.tsx`。

## 5. 文件传输工具栏按钮点击无反应
- 根因：工具栏的新建/重命名/删除依赖浏览器原生 `prompt()`/`confirm()`；在 Electron 打包环境下这些弹窗可能不显示或被忽略，导致用户感觉“点击没效果”。另外远端未连接时按钮 disabled 但缺乏状态提示，重命名/删除在未选中时也会 disabled。
- 修复：
  - `src/components/FileManager.tsx` 内新增自定义输入/确认弹窗（`dialog` 状态 + `showPrompt`/`showConfirm`），替代所有 `prompt`/`confirm`；弹窗支持 Enter 确认、Esc 取消、自动聚焦。
  - 操作前后通过底部状态栏即时反馈（“请输入...”“正在删除...”“已创建...”）。
  - 远端 Pane 标题旁增加“未连接”标签；工具栏按钮 title 在 disabled 时提示原因（远端未连接 / 请选中一个项目 / 请先选中要删除的项目）。
  - 按钮增加 `active:scale-95` 与 `active:bg-*` 触觉反馈。
- 附带修复：`index.html` 中的 Vite 开发期 inline script module 导致生产构建报错 `html-proxy not found`，已删除（生产不需要该错误监听）。
- 验证：`npm run check`/`npm run build` 通过；`env -u NODE_OPTIONS npm run dist` 成功产出 `release/0.1.0/TermAI 0.1.0.exe` 与 `TermAI Setup 0.1.0.exe`；asar 解包产物包含“请输入/新建文件夹/确认删除/未连接/重命名”等字符串。
