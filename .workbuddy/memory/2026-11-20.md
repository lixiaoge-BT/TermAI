## 修复 SysMon CPU 显示 0% 的假象
- 现象：面板 CPU 0%，但 top 显示 0.1us+0.1sy（≈0.2%）；折线贴底像没监控。
- 定位：`dist-test/run-sysmon-cpu.mjs` 探针复算 → 24 核 2s 内忙 10/4800 jiffies = 0.2083%，**计算本身准确**，是展示层 `Math.round(0.2)=0` 抹掉精度。
- 修复（`src/services/sysmon.ts` + `src/components/SysMon.tsx`）：
  - `formatPercent(v)`：0→`0%`，<10 保留 1 位小数，≥10 取整；状态栏与弹层统一走它。
  - `cpuChartMax(values)`：CPU 折线量程自适应（峰值 <10 → 1/2/5/10；≥10 回 100），并在弹层标注「刻度 N%」避免误读成满载。
  - `MiniBar`：有值至少 2px（`max(2px, N%)`），低占用不再与 0% 混淆。
- 验证：`npm run check` 通过；`npm test` 628/628（新增 3 例）；`npm run build:renderer` 成功；探针确认打包后 `formatPercent(0.2083)="0.2%"`。
- 经验：多核机器整机 CPU 天然是「单进程%÷核数」量级，显示精度必须先于计算优化怀疑。

## 修复主机列表面板分隔线生硬
- 现象：红框标出左侧主机列表，主机项之间的横线是亮白色、很扎眼。
- 根因：`HostPanel.tsx` / `SessionPlayer.tsx` 用了 `border-border-tertiary`，但 `tailwind.config.js` 的 colors 只映射了 border-primary/secondary，且 `index.css` 也没定义 `--border-tertiary` → 该类**根本没生成**，只剩 `border-b` 的宽度，颜色回退成 `currentColor`（文字色 #c9d1d9 亮灰）。核验手法：`grep -oE '\.border-border-tertiary' dist/assets/*.css` 为空即可确认类未生成。
- 修复：`index.css` 补 `--border-tertiary`（dark `rgba(240,246,252,.06)` / light `rgba(31,39,49,.025)`）+ `tailwind.config.js` 补映射；分组标题 sticky 线从 border-primary 降到 border-secondary（保留层级感但不再抢眼）。
- 验证：`npm run check` 通过、`npm test` 628/628、`npm run build:renderer` 成功；CSS 确认 `.border-border-tertiary{border-color:var(--border-tertiary)}` 已生成。
- 视觉核验：`dist-test/preview/border-compare.html` + `SHOT_*` 环境变量走 electron 的 `shot.cjs`；截图 `border-compare.png` 证实修复后线条极淡、层级仍可辨。
- 坑：截图脚本必须用 `./node_modules/.bin/electron dist-test/preview/shot.cjs` 跑，直接 `node shot.cjs` 会 `app undefined`；且必须 `env -u ELECTRON_RUN_AS_NODE -u NODE_OPTIONS`。

## 修复分屏后失焦窗格光标变方块
- 现象：分屏后其中一个窗格光标变成蓝色空心方块（▯），未分屏时一直是 2px 竖条。
- 根因：xterm 5.3 默认 `cursorInactiveStyle: "outline"` —— 失焦窗格把光标画成空心方块；项目只设了 `cursorStyle: "bar"`，没覆盖失焦态。
- 修复：`XTerminal.tsx` 的 `assertBlinking()` 和 `new Terminal({...})` 初始配置都加 `cursorInactiveStyle: "bar"`，保证失焦也保持竖条。
- 验证：`npm run check` 通过、`npm test` 628/628、`npm run build:renderer` 成功；真实 xterm 双窗格探针 `dist-test/preview/cursor-inactive.html` + `shot.cjs` 截图确认聚焦/失焦光标均为竖条、形态一致。
- 坑：探针页两个窗格总宽要小于 SHOT_WIDTH，否则出横向滚动条把右侧窗格挤没；截图脚本仍需 electron 二进制 + 清 env。
