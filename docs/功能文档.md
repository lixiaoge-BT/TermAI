# TermAI 功能文档

> 版本：v0.1.0 · 更新时间：2026-09-01

---

## 1. 产品定位

TermAI 是一款 **AI 增强的终端 / SSH 客户端**（类 Xshell），基于 Electron + React + TypeScript 构建。

它把「传统终端」和「AI 助手」放在同一界面：既能像普通 SSH 客户端一样操作服务器，也能让 AI **真正接管终端**——下发命令、读回真实输出、基于退出码决定下一步，而不是凭空编命令给你看。

一句话区分三类能力：

| 能力 | 谁执行 | 典型场景 |
| --- | --- | --- |
| 普通终端 | 人 | 日常运维操作 |
| AI 问答 | 人 | 「8080 端口被谁占了」→ AI 给命令 → 你复制执行 |
| Agent 接管 | AI | 「帮我装好 Nginx 并配好反向代理」→ AI 自己跑完整个过程 |

## 3. 主机管理

### 3.1 主机列表

左侧面板，可折叠为 56px 竖条。

- **分组**：树状归类，可折叠；空分组也会显示；未分组排在最后
- **搜索**：按名称 / 地址 / 用户名 / 标签模糊匹配，搜索时自动展开所有分组
- **拖拽**：把主机拖到分组标题上即可移动归属
- **标签**：回车添加，可打多个。命中 `/生产|prod|线上|live/i` 的标签会触发**生产环境额外安全确认**
- **状态指示**：右侧圆点显示当前该主机的活跃会话数；被激活标签页使用的主机会标「使用中」
- **右键菜单**：文件传输 / 端口转发 / 连接 / 编辑 / 删除

### 3.2 主机配置字段

| 字段 | 说明 |
| --- | --- |
| 连接名称 | 显示名 |
| 主机 / 端口 | 地址与 SSH 端口，默认 22 |
| 用户名 | 默认 root |
| 认证方式 | 密码 或 私钥（PEM 全文粘贴）+ 可选私钥口令 |
| 跳板机 | 引用另一台已配置主机作为 ProxyJump |
| 分组 | 下拉选择或直接输入新建 |
| 标签 | 多值，回车添加 |

### 3.3 跳板机（ProxyJump）

用于「本机 → 跳板机 → 内网目标」的多跳场景。选择跳板机后，连接先建立到跳板机，再从跳板机内部转发到目标主机。跳板机候选自动排除自身，避免自引用。

### 3.4 导入导出

- **导出**：明文 JSON 下载，文件名 `termai-hosts-YYYY-MM-DD.json`。**含密码 / 私钥 / API Key 明文**，导出前有二次确认弹窗，仅用于本机备份或换机迁移
- **导入**：按 `id` 合并——已存在则更新，不存在则新增。导入后提示「新增 N 台，更新 M 台，分组 K 个」

## 4. 终端

### 4.1 SSH 远程终端

- **多标签会话**：每个标签一个独立 SSH 连接，状态独立维护
- **连接状态机**：`idle → connecting → connected → reconnecting / disconnected / error`
- **自动重连**：断线后按指数退避自动重试，终端内实时提示「连接断开，正在重连（第 X/Y 次，Ns 后重试）…」
- **尺寸同步**：终端容器尺寸变化（`ResizeObserver`）自动 `ssh:resize`。建连时也会带上真实 cols/rows，避免远端 PTY 停在 80×24 导致换行错位
- **端口转发自动恢复**：连接建立后，主机配置里 `enabled: true` 的转发项自动重建

### 4.2 本地终端

基于 `node-pty` 的真 PTY。Windows 默认 PowerShell，Unix 取 `$SHELL` 或 `/bin/bash`。支持完整的 shell 交互（tab 补全、信号处理、`Ctrl+C` 等原生行为）。

### 4.3 分屏

- 任意面板可横向 / 纵向切分
- 拖拽分隔条调整比例（`setSplitRatio`）
- 每个面板可绑定不同会话
- **面板清理规则**：会话关闭后，已不存在的会话置空；同一会话出现在多个面板时聚焦面板优先保留；空面板先用其他会话顶替，否则关闭——但**永远至少保留一个面板**
- 连接中 / 错误状态下面板必须露出终端本体，否则「正在连接…」或「连接失败：xxx」会被遮罩盖住，用户会误以为连不上

### 4.4 终端交互

| 操作 | 行为 |
| --- | --- |
| 右键 | 粘贴剪贴板内容 |
| 选中文本 | 自动复制到剪贴板（`onSelectionChange`） |
| `Ctrl/Cmd + F` | 打开终端内查找浮层（基于 xterm SearchAddon） |
| `Ctrl + 滚轮` | 缩放字号 |
| 输入 `?问题` 回车 | 唤起 AI 侧边栏并自动提问 |
| 光标闪烁 | 关闭 xterm 原生 blink（原生 blink 会导致光标所在行邻字忽明忽暗），改由 CSS 动画驱动 |

## 5. AI 问答侧边栏

右侧面板，宽 420px（可缩至 360px，最大占 40%），可折叠为竖条。

### 5.1 两种模式

| 模式 | 说明 |
| --- | --- |
| **AI 问答** | 对话式，AI 给解释 / 建议 / 命令，由你决定是否执行 |
| **Agent 接管** | AI 自己下发命令执行，见第 6 节 |

两个模式**都保持挂载，只切换 display**，避免切模式时丢失对话 / 任务上下文。

### 5.2 上下文感知

AI 会自动读取当前会话的上下文，你不需要复制粘贴报错：

- 主机 IP、主机名、当前用户、主机标签
- **最近 80 行终端输出**
- **命令历史**（含你执行过的每条命令）

侧边栏右下角有个上下文信息按钮，点开可以看到 AI 实际拿到了哪些内容。未连接主机时也能问纯知识性问题（此时用 `__global__` 对话桶）。

### 5.3 对话体验

- **流式输出**：SSE 逐 token 渲染，60ms 节流刷新，不会「等半天没反应」
- **停止生成**：生成中点「停止生成」发 `AbortController.abort()`
- **会话隔离**：对话按终端会话隔离存储，切换标签页看到的是各自独立的对话。切换会话时自动清空输入框草稿，避免把 A 会话没发出去的内容误发到 B
- **清空对话**：每个会话独立清空
- **快捷提示词**：分析终端错误 / 分析我的操作 / 诊断系统资源 / 查看端口占用 / 安装 Nginx / 备份脚本

### 5.4 命令卡片

AI 回复里的 ```bash 代码块会被解析成**命令卡片**，而不是纯文本：

```
┌────────────────────────────────────┐
│ $ lsof -i :8080          [低风险]  │
│ [复制到终端]  [执行]  [复制]        │
└────────────────────────────────────┘
```

- 风险等级徽章（none / low / medium / high / critical）
- 高危命令点「执行」会弹二次确认，勾选确认项才能放行
- 支持 `:risk=high` 语法在代码块语言后手工标注风险

### 5.5 终端快捷提问

在终端里直接输入 `?你的问题` 回车（如 `?为什么 nginx 启动失败`），自动唤起 AI 侧边栏并发送。

> 实现注意：`termai:quick-ask` 事件**只允许一个监听器**（在 `Home` 的 QuickAskBridge）。如果 AISidebar 也监听，同一次提问会被发送两遍。

### 5.6 报错自动分析

开启后（AI 设置里的开关），终端输出命中错误关键词时 AI 自动介入分析并给出修复命令。

- 关键词正则覆盖：`error / failed / fatal / exception / denied / refused / not found / command not found / permission denied / segfault / panic / traceback / timeout / abort / critical / unreachable` 等
- **20 秒防抖**，避免刷屏
- 需要已配置 API Key 才会生效

## 6. Agent 接管终端

这是 TermAI 的核心差异化能力。AI 不只给建议，而是**真实接管终端把事办完**。

### 6.1 执行循环

```
用户输入目标（如「帮我装好 Nginx 并配好反代」）
   │
   ▼
┌──────────────────────────────────────┐
│ 1. 组装 system prompt + 上下文         │
│ 2. 调 LLM，流式展示「思考过程」         │
│ 3. 解析 <<<RUN>>> 块 → 命令列表         │
│ 4. 逐条安全审查 → 风险分级              │
│ 5. 需要确认的命令挂起（awaiting-confirm）│
│ 6. 下发执行，哨兵协议取回输出 + 退出码   │
│ 7. 把观察结果回传 LLM                  │
│ 8. 上下文超预算 → 自动压缩              │
│ 9. 回到 2，直到 <<<DONE>>> 或达到上限    │
└──────────────────────────────────────┘
   │
   ▼
展示步骤时间线 + 最终总结
```

### 6.2 哨兵协议

终端是流式 PTY，没有「命令返回值」。TermAI 用三个唯一哨兵从数据流中精确切分：

```bash
echo "TERMAI_BEGIN_<token>"
<实际命令>
echo "TERMAI_EXIT_<token>=$?"
echo "TERMAI_END_<token>"
```

- BEGIN / END 要求**独占一行**匹配，从而跳过 PTY 对整条脚本的回显
- 支持 heredoc / 多行脚本：落盘为临时脚本执行，结束后自动清理
- 同时拿到 stdout+stderr 合并输出与真实退出码

### 6.3 批量探测

模型可以在一个 `<<<RUN>>>` 块里给多条**彼此无依赖的只读命令**，引擎按顺序全部执行后一次性回传。这样把多次 AI 往返压缩成一次，显著提速。

`<<<RUN>>>` 内容解析时会容忍模型自作主张加的序号（`1.` `-` `•` `*`），并过滤注释行。

### 6.4 超时策略

| 参数 | 默认值 | 行为 |
| --- | --- | --- |
| `commandTimeoutMs` | 20000 | 基础超时。**超时后若仍在持续产生输出会自动延长** |
| `commandMaxTimeoutMs` | 60000 | 硬上限，无论如何到此为止 |

超时**不抛异常**，返回已收集到的全部输出并置 `timedOut = true`，让模型基于部分输出继续决策。

### 6.5 风险确认

| 风险等级 | 行为 |
| --- | --- |
| `none` / `low` | 始终自动执行 |
| `medium` | 受「中风险自动执行」开关控制（`autoRunMedium`） |
| `high` / `critical` | **始终弹确认** |

确认时的三个选项：

- **执行**（run）
- **跳过**（skip）——这条不跑，任务继续
- **中止**（abort）——整个任务停止

### 6.6 上下文预算控制

Agent 多步任务的上下文会线性膨胀。`src/lib/contextCompression.ts` 做三件事：

- `estimateTokens` / `estimateMessagesTokens` 估算 token 占用
- `shouldCompress` 触发压缩：把早期对话让 LLM 总结成【历史上下文摘要】（上限 2200 字），替换原始消息
- `trimMessages` 兜底裁剪

避免 token 线性膨胀导致请求失败或成本失控。

### 6.7 防死循环

模型经常不按协议输出。解析器的兜底链：

1. 命中 `<<<DONE>>>` → 结束，其前的命令作废
2. 命中完整 `<<<RUN>>>…<<<END>>>` 且解析出命令 → 执行
3. 只有开标记没有闭标记 → 从开标记截取到结尾解析
4. 完全没按协议 → **整段当作最终结论，强制 `done = true`**

第 4 条是关键：宁可提前结束，也不让任务无限空跑。

### 6.8 步骤时间线

UI 展示每一步的状态（`pending / running / done / failed / skipped`）、命令、退出码、输出摘要，以及模型流式输出的「思考过程」（`liveThought`）。任务结束后给出 `summary` 总结。

随时可点「停止」中断，会话关闭时自动 `dispose` 中断并释放资源。

## 7. 命令安全审查

本地规则引擎（`src/services/safety.ts`），**不依赖 AI**，零延迟零成本。

### 7.1 五级风险

| 等级 | 含义 | 强制确认 |
| --- | --- | --- |
| `none` | 空命令 | 否 |
| `low` | 只读命令 | 否 |
| `medium` | 一般写操作 | 生产环境需确认 |
| `high` | 危险操作 | 是 |
| `critical` | 破坏性操作 | 是 |

### 7.2 判定顺序

1. **空命令** → `none`
2. **高危模式匹配**（`DANGEROUS_PATTERNS` 正则表）
   - `rm -rf /`、递归删除根目录
   - 磁盘格式化 / `mkfs` / `dd` 写设备
   - `DROP DATABASE` / `TRUNCATE`
   - 卸载 `glibc` / `systemd` / `bash` / `kernel` 等系统核心包
   - 命中即返回对应风险等级与中文风险描述
3. **只读白名单**（`READONLY_COMMANDS`）
   - `ls cat grep head tail less find du df free top htop ps ss netstat ip ifconfig uname whoami env history curl -I ping dig` 等 60+ 命令
   - 自动剥掉 `sudo` / `doas` / `pkexec` / `su -c` 前缀再判定
   - 管道组合要求**每一段都只读**才算安全
   - 含 `>` 重定向一律不算只读（避免 `cat a > b.txt` 被误判）
4. **其他** → `medium`，生产环境默认需确认

### 7.3 生产环境加成

主机标签命中 `/生产|prod|线上|live/i` 时：

- 高危命令的确认项列表最前面插入「⚠️ 当前为主机已标注【生产环境】」
- `medium` 风险也默认需要确认

## 8. 文件传输（SFTP）

双栏文件管理器，本地 ⇄ 远程。

### 8.1 功能

| 功能 | 说明 |
| --- | --- |
| 双栏浏览 | 左本地、右远程，各自独立路径与选中集 |
| 本地起始目录 | 默认打开桌面，不可用时回退到第一个盘符 |
| 上传 / 下载 | 支持多选；实时进度条（`sftp:progress` 事件） |
| 新建目录 | 本地与远程都支持 |
| 重命名 / 移动 | 本地与远程都支持 |
| 删除 | 本地与远程都支持，远程需指定 `isDir` |
| 盘符切换 | Windows 下可切 `C:\` `D:\` 等 |
| 地址栏 | 路径分段可点击跳转 |

### 8.2 传输进度

```ts
{
  transferred: number,   // 已传输字节
  total: number,         // 总字节
  direction: "download" | "upload",
  remotePath: string,
  localPath: string
}
```

### 8.3 安全提示

- 自定义确认弹窗替代 `prompt` / `confirm`——Electron 下原生弹窗可能不显示或无反馈
- 本地删除是**递归删除且不经回收站**，弹窗明确提示后再执行

## 9. 端口转发

按主机配置，连接建立后自动恢复 `enabled: true` 的项。

### 9.1 三种类型

| 类型 | 命令等价 | 行为 |
| --- | --- | --- |
| **本地转发**（local） | `ssh -L` | 监听本机 `localPort` → 经隧道到 `remoteAddress:remotePort` |
| **远程转发**（remote） | `ssh -R` | 远端监听端口 → 流量回到本机目标 |
| **动态转发**（dynamic） | `ssh -D` | 本地起 **SOCKS5 代理**，目标由 SOCKS 客户端在连接时动态指定 |

### 9.2 端口分配

`localPort = 0` 时由系统随机分配，实际端口通过 `SshForwardStatus.bindPort` 回填。转发状态通过 `ssh:forward` 事件实时推送到 UI（建立 / 失败 / 断开），失败时 `status.error` 携带原因（如端口被占用）。

### 9.3 SOCKS5 实现

动态转发在 `electron/main/socks5.ts` 内置了一个精简 SOCKS5 服务器：解析客户端 CONNECT 请求，取出目标 host:port，通过 SSH 通道建立连接并回 success 应答。浏览器 / 其他应用把代理指向该端口即可走内网。

## 10. 操作录制与回放

### 10.1 录制

- 每个会话独立录制，工具栏一键开关
- 记录**每一条命令及其对应输出**（不只是屏幕录像），结构化存储
- 实时显示已录制时长
- 录制内容会清洗 ANSI 转义序列并统一换行
- 关闭会话时自动停止并保存；应用退出时 `stopAllRecordings()`

### 10.2 回放库

- 列表展示：名称、时长、大小、创建时间
- 支持重命名、删除、在文件管理器中打开目录
- 回放界面按操作逐条展示，可 hover 高亮、pin 固定
- 存储位置：`<userData>/recordings/*.json`

## 11. 凭据与配置存储

### 11.1 加密存储

SSH 密码、私钥、私钥口令、AI API Key 在**落盘前**经 Electron `safeStorage` 加密：

- Windows：DPAPI（绑定当前用户账户）
- macOS：Keychain
- Linux：libsecret

格式：`ENC:` + base64。解密时若无 `ENC:` 前缀按旧明文处理，保证老版本配置升级平滑。平台不支持加密时**静默降级为明文存储并在 UI 提示**，保证功能可用。

### 11.2 持久化范围

| Store | 键名 | 内容 |
| --- | --- | --- |
| `config` | `termai-config-v1` | 主机列表、分组、AI 配置、主题 |
| `chat` | — | AI 问答对话记录（按会话隔离） |
| `terminal` / `layout` / `forward` / `agent` | — | **内存态**，重启后不保留（会话和布局重来） |
| `recordings` | `<userData>/recordings/` | 操作记录 JSON 文件 |

> 会话列表、分屏布局、Agent 任务状态不持久化——重启应用后需要重新连接，这是有意为之（SSH 连接本来也不可能跨进程存活）。

---

## 12. 主题

支持 `dark` / `light` / `system` 三档，`system` 跟随系统 `prefers-color-scheme`。终端配色（`xterm` theme）随主题切换，同时联动 `matchMedia` 监听系统变化。

## 13. 典型操作流程

### 13.1 连接第一台主机

1. 左侧主机面板点右上角 `+` → 新建主机
2. 填名称、地址、端口、用户名，选密码或私钥认证
3. （可选）选分组、加标签、配跳板机
4. 保存后双击主机项，或点「连接」

### 13.2 让 AI 排查故障

1. 连上主机，跑一条出错的命令
2. 侧边栏点「分析终端错误」，或直接在终端输入 `?为什么这条命令报错` 回车
3. AI 读取终端上下文给出原因和修复命令
4. 在命令卡片上点「执行」，或复制后自己跑

### 13.3 让 Agent 完成一个完整任务

1. 连上主机，切到「Agent 接管」模式
2. 输入目标，如「帮我装好 Nginx，配置反向代理到本机 3000 端口」
3. Agent 自动：探测系统 → 装包 → 写配置 → 校验语法 → 启动服务 → 验证端口
4. 遇到高风险命令会挂起等你确认（执行 / 跳过 / 中止）
5. 过程中可随时点「停止」，右侧时间线实时展示每一步

### 13.4 通过跳板机访问内网机器

1. 先把跳板机配置成一台普通主机
2. 新建内网目标主机，在「跳板机」下拉里选中那台跳板机
3. 正常连接即可，链路自动变成 本机 → 跳板机 → 内网目标

### 13.5 给内网服务开代理

1. 主机右键 → 端口转发
2. 新建，类型选「动态转发」，本地端口填 1080（或 0 随机）
3. 浏览器代理设置指向 `127.0.0.1:1080`
4. 即可直接访问内网地址

## 14. 边界与已知限制

| 限制 | 说明 |
| --- | --- |
| AI 供应商 | 仅支持 OpenAI 兼容 API（`/v1/chat/completions`）。`anthropic` 未实现，调用会抛错提示 |
| 历史对话长度 | 问答模式只取最近 20 条消息（约 10 轮）送入模型；Agent 模式靠上下文压缩控制 |
| 主机导入格式 | 仅支持 TermAI 自身导出的 JSON。**不支持** Xshell / SecureCRT 会话文件导入（接口预留，未实现） |
| 本地删除 | 递归删除且不经回收站，不可恢复 |
| 明文导出 | 主机导出文件含密码 / 私钥 / API Key 明文，务必妥善保管 |
| 布局持久化 | 分屏布局不保存，重启后回到单面板 |
| Agent 最大步数 | 有步数与超时兜底，超限时任务自动停止并给出当前进度总结 |
| node-pty | 首次使用本地终端可能需要原生模块重建，见 README |
